# Marbles

An offline-first PWA for logging deep work. Every session becomes a glass marble sized by its duration.

- `npm run dev` — develop
- `npm run build` — type-check and build to `dist/` (also writes the service worker)
- `?demo=1` — seeds ~150 sample sessions into a separate database

Data lives in IndexedDB on the device. Export JSON from the ··· menu to back it up.
